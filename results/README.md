# Recorded experiment results

The CSV tables are transcribed from the saved outputs accompanying the original analysis. They are historical records, not measurements regenerated by packaging or by the smoke check.

- `model_comparison.csv`: saved main comparison output; held-out metrics are single scores on the fixed test set. CV F1 means are recorded to four decimals; CV standard deviations are available only rounded to three decimals.
- `feature_selection.csv`: saved feature-selection comparison; test metrics are mean and population standard deviation across 100 ordinary bootstrap resamples of the same encounter-level test set, using fixed fitted models. Encoded feature counts are from the saved dimensionality output.

The random forest's single held-out F1 is 0.5330, whereas its rounded bootstrap mean F1 is 0.532. These are different summaries and are deliberately not substituted for one another. Likewise, rounded bootstrap ROC-AUC values both read 0.683; an older narrative describes a change at greater precision that cannot be recovered from this rounded table.

Five model/diagnosis plots exported from notebook outputs preserve the recorded experiment. The two model-result summary charts are drawn from these result CSVs, and the target-distribution chart uses verified full-dataset class counts. None of these three regenerated charts fits models. Original fitted estimator objects and per-encounter predictions are unavailable, so historical results cannot be independently reconstructed from saved outputs alone. Running the notebook produces new estimators and results; library versions and runtime differences may change them.

Regenerate the summary charts from the repository root:

```bash
python scripts/plot_recorded_results.py
```
